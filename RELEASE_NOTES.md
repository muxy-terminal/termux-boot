# termux-boot 0.8.1+muxy.6

Coordinated source-built release for muxy 0.119.10. Package name, shared UID, permission checks, and private signer are unchanged. Install over earlier muxy-signed builds without uninstalling.

Standalone runtime behavior is unchanged. The higher version code identifies this coordinated build.

Source, licenses, provenance, and checksums accompany the APK. Differently signed upstream, F-Droid, and Play APKs cannot share muxy UID. Physical-device idle and per-addon host integration limits remain documented in the combined release.
